PERSONAL AUTOMATION / 個人自用工具

本機工作與 Google Drive 之間的受控橋接

Kan Local Commander（KLC）是供持有人自行使用的 Windows 本機自動化工具，將經授權的 Google Docs 任務轉為受限制的本機工作，並將執行結果寫回專用 Google Drive 資料夾。

KLC is a personally operated Windows automation bridge. It reads authorized Google Docs tasks, processes a constrained set of local operations, and writes receipts back to app-specific Google Drive folders.

功能與範圍 / Functionality

任務來源

辨識持有人私人、指定命名格式的 Google Docs，讀取任務 JSON，透過 HMAC 簽章佇列送至本機。

本機執行

僅支援明確限定的 ping、list、read、create 與受保護的 replace；不開放任意 Shell 指令。

結果回傳

執行結果、錯誤與核對回條會保存至專用 Google Drive 資料夾及本機紀錄，供持有人查閱。

Google 資料權限 / Google Data Access

本工具要求 Google Drive 中繼資料唯讀、Google Docs 文件唯讀，以及應用程式建立或獲授權檔案的 Drive 寫入權限。讀取權限在 OAuth 層級可能涵蓋比實際處理範圍更大的資料；KLC 程式只處理符合設定的任務來源。

Requested scopes include Drive metadata read-only, Docs read-only and limited Drive file write. The OAuth read scopes may grant broader visibility than the documents processed by the application's own rules.

本工具目前供單一持有人自用，不提供公開註冊或商業雲端代管服務。

This is a single-owner, self-operated tool, not a public SaaS or account-registration service.
